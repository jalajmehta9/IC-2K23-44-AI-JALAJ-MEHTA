
# Machine Learning Practicals

This repository contains four Python-based Machine Learning projects implemented using Scikit-learn, Pandas, NumPy, and Matplotlib.

## Projects Included

### 1. Student Placement Prediction
- Predicts whether a student will get placed based on CGPA and IQ.
- Algorithm: Logistic Regression.
- Uses classification to predict placement status.

### 2. Disease Prediction
- Predicts the possibility of diabetes using health-related parameters.
- Features: Glucose, BMI, and Age.
- Algorithm: Decision Tree Classifier.

### 3. Loan Approval Prediction
- Predicts whether a loan application will be approved or rejected.
- Features: Income, Loan Amount, Credit History, and Employment Status.
- Algorithm: Logistic Regression.
- Uses Label Encoding and Standard Scaling.

### 4. Decision Tree Visualization
- Implements a Decision Tree Classifier using the Iris dataset.
- Visualizes the decision-making structure of the trained model.
- Algorithm: Decision Tree Classifier.
- Uses Matplotlib for visualization.

## Installation

Make sure Python 3 is installed on your system.

Install the required libraries:

```bash
pip install pandas numpy matplotlib scikit-learn
```

## How to Run

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd Machine-Learning-Practicals
```

Run individual programs:

```bash
python student_placement.py
```

```bash
python disease_prediction.py
```

```bash
python loan_approval.py
```

```bash
python decision_tree_visualization.py
```
